# DL-BASES

Personal refresher and hands-on training project to rebuild and strengthen my
Deep Learning fundamentals.

The goal is to understand the theory, mathematics and implementation behind
the main Deep Learning architectures through notes, notebooks and small
experiments.

## Topics

### Feed-Forward Neural Networks (ANN)

- Perceptrons and fully connected layers
- Forward propagation
- Activation functions
- Loss functions
- Backpropagation
- Gradient descent and optimization
- Regularization

### Convolutional Neural Networks (CNN)

- Images as tensors
- Convolution and filters
- Feature maps
- Pooling
- CNN architectures
- ResNet and modern architectures
- Object detection
- Transfer learning and fine-tuning

### Recurrent Neural Networks (RNN)

- Sequential data
- Recurrent connections
- Hidden states
- Vanilla RNN
- LSTM
- GRU
- Sequence prediction

### Transformers

- Attention mechanism
- Self-attention
- Multi-head attention
- Positional encoding
- Encoder / Decoder architecture
- Transformer-based models
- Applications to NLP and sequential data

### Auto-Encoders

- Encoder / Decoder architecture
- Latent representations
- Reconstruction loss
- Dimensionality reduction
- Denoising auto-encoders
- Variational Auto-Encoders (VAE)

## Foundations

The different topics are supported by the fundamental concepts required to
understand and implement Deep Learning models:

- Linear algebra
- Vectors, matrices and tensors
- Derivatives and gradients
- Probability and statistics
- Optimization
- Loss functions
- Automatic differentiation
- GPU and batch computation
- Training, validation and testing
- Overfitting and regularization

## Learning Approach

Each topic is studied through:

- Short theoretical notes
- Mathematical derivations
- From-scratch implementations
- Jupyter notebooks
- Small experiments
- Model training and evaluation
- Visualizations and analysis

The objective is not only to use Deep Learning frameworks, but to understand
what happens behind the abstractions.
